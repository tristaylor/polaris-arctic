# Scientific gap and prior art

NOAA's 2025 Arctic observing-network assessment identifies gaps in finer-scale coverage, nearshore observations, and validation. POLARIS addresses a narrower question. At one accessible site, can a fixed sampler obtain a usable physical sample during a transient turbidity excursion that a scheduled program with the same number of cartridges would miss? Start with controlled sediment pulses and a time-matched reference. A turbidity excursion is a proxy for a change in optical conditions. Bubbles, fouling, sediment properties and sensor drift can all change the signal.

| Prior work | Relevance to POLARIS |
|---|---|
| [NOAA Arctic observing-network assessment](https://arctic.noaa.gov/report-card/report-card-2025/assessing-the-state-of-the-arctic-observing-network-strengths-gaps-and-risks-to-systems-that-track-arctic-change/) | Motivates finer-scale observations. Does not establish demand for this instrument. |
| [Khamis et al., Autobot-WQ (2023)](https://doi.org/10.3389/fbuil.2023.1072757) | Demonstrates low-cost portable autosampling for urban water quality. Use as a design and cost comparator with operating context stated. |
| [MBARI FIDO](https://www.mbari.org/news/mbaris-new-robotic-sampler-aims-to-transform-monitoring-of-aquatic-ecosystems/) | Establishes precedent for autonomous cartridge-based aquatic sampling and preservation. POLARIS Phase I uses water and physical measurements only. |

The proposed contribution is a measured tradeoff among event coverage, sample validity, cold-weather operating limits and cost for a small stationary instrument. Two cartridges limit mission coverage. Event selection biases samples toward the trigger variable and cannot support prevalence or seasonal inference on its own. Keep scheduled baseline observations and report all missed events, suppressed triggers and rejected samples. Future chemistry or biodiversity cartridges would require separate assay, preservation and contamination validation.
